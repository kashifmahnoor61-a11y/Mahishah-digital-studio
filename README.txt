# Mahishah Digital Studio

A simple, responsive personal portfolio website.

## Preview
Open `index.html` in Chrome.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with a safe contact email only if you and a parent/guardian agree it is okay to publish.
2. Add only skills you can confidently offer.
3. Replace the "Coming soon" portfolio cards with practice samples that contain no private information.
4. Do not publish your home address, personal phone number, passwords, OTPs, school details, or private documents.

This is a static starter website. It does not include hosting, a custom domain, payments, or a working contact form service.
